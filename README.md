# Projeto React com Supabase — Notas Rápidas

## Descrição

Este projeto foi desenvolvido utilizando React Javascript integrado ao Supabase como Backend as a Service (BaaS).

O objetivo do aplicativo é permitir o cadastro e visualização de notas rápidas.

## Tecnologias Utilizadas

* React Javascript
* Supabase
* PostgreSQL

## Funcionalidades

* Inserir novas notas
* Listar notas cadastradas

## Estrutura da Tabela

Tabela: notas

Campos:

* id
* titulo
* conteudo
* created_at

## Como executar o projeto

```bash
npm install
npm start
```

## Integração com Supabase

O projeto utiliza a biblioteca oficial:

```bash
npm install @supabase/supabase-js
```

A conexão foi realizada utilizando a URL do projeto e a chave pública fornecidas pelo Supabase.
